## Correctness and limitations

- SQL expected counts were computed before measurement from the demo account, and every returned ID was checked against its account-owned ID set. All page metadata, relevant item predicates, sort direction, and Daily Plan grouping/partition were checked per response. Later pages were checked for non-overlap with page 0.
- A1/A2 isolation preflight: a1 notes 123/123, leaked first-page IDs=0; a1 tasks 144/144, leaked first-page IDs=0; a2 notes 268/268, leaked first-page IDs=0; a2 tasks 418/418, leaked first-page IDs=0.
- Single local Windows/JVM/PostgreSQL environment; client-side timings include local HTTP and PowerShell overhead. This is a reproducible baseline, not a throughput or scalability claim. No 5,000/5,000 profile was run.
